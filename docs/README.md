# Documentation

Start with [Check a Python answer](tutorials/checked-python.md). To work directly with the machine, try [compiled C](tutorials/compiled-c.md) or the [transformer tutorial](tutorials/first-program.md).

- [Tutorials](tutorials/README.md): worked examples with expected output.
- [How-to guides](how-to/README.md): scoring, testing, the iCEstick, and migrating old code.
- [Reference](reference/README.md): APIs, language support, opcodes, and hardware formats.
- [Explanation](explanation/README.md): arithmetic, architecture, and the LOOM fork.

Commands assume the repository root. Hardware instructions name the FPGA image they need; the ISA and transformer MAC images use different UART protocols.
